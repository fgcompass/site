    How it works

    Watch, answer, score. That's it.

    1. 1

      Watch the child perform a skill

      Observe live, in the gym, playground or clinic. A short protocol covers setup, instructions and trials for each skill.

    2. 2

      Answer two yes/no questions

      The first question points toward the lower or upper levels. A second question confirms where the child lands.

    3. 3

      Record a level from 1 to 4

      A level for each skill builds the child's profile, so you can track progress or compare before and after a program.

    One tree, four possible paths

    Every skill uses the same three-question tree. Each child follows one path: a key question, then one confirming question.

    For researchers: the composite decision-tree model

    FG-COMPASS is a process-oriented, criterion-referenced instrument. Each skill is scored with a composite decision tree that combines the Observational Plan and Three-Stage approaches to FMS assessment, using only three key performance criteria drawn from validated and hypothesized developmental sequences.

    • Discriminatory question (DQ) separates the extremes (levels 1 and 4).
    • Upper confirmatory question (UCQ) confirms level 4; if not confirmed, the child is level 3.
    • Lower confirmatory question (LCQ) confirms level 1; if not confirmed, the child is level 2.

    • Hopping

    • Vertical jump

    • Batting
    • Stationary dribble

    The evidence

    Built on more than 15 years of research.

    Developed at the University of Pittsburgh and tested for reliability and agreement with expert raters in peer-reviewed studies.

    Why movement skills matterChildren who move well tend to be more active. Research links these skills to healthier body composition, working memory and more confident play with peers.
